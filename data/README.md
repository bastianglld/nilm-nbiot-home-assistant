# Données

Les données brutes ne sont pas versionnées dans ce dépôt (dossier `data/raw/`, ignoré par Git).

## Jeu de données public

- Nom : à compléter (par exemple REDD, UK-DALE ou REFIT)
- Lien : à compléter
- Licence : à compléter

Placez les fichiers téléchargés dans `data/raw/` et ne les ajoutez jamais à Git.

## Mesures réelles

Anonymisez-les avant de les versionner, car elles peuvent révéler les habitudes du foyer.
